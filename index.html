MouseFlow

Connect the local agent

A browser tab can only see mouse events inside its own window, and cannot inject real clicks. The agent is the piece that records your desktop and replays it. It runs on your machine and talks to this page over loopback only.

  1. Download mouseflow-agent.ps1
  2. Open PowerShell in that folder and run:
    powershell -ExecutionPolicy Bypass -File .\mouseflow-agent.ps1
  3. Leave that window open. This page reconnects on its own.

The agent installs a low-level mouse hook while it runs. Events are only stored between Start and Stop. Run it with -AllowOrigin set to this page's origin so other sites cannot reach it.
