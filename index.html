        Advanced

        To stop the agent, close its PowerShell window. There is no other off switch, and nothing here can stop it for you — that is deliberate: a page cannot be allowed to shut down a program on your machine.

        The agent installs a low-level mouse hook while it runs. Events are only stored between Start and Stop, nothing is written to disk, and the agent has no outbound network code. Keep -AllowOrigin pinned to this page's origin so other sites cannot reach it.
